# Analisis-Basis-Data-Akademik-Menggunakan-SQL
Proyek ini merupakan bagian dari tugas mata kuliah Rekayasa Data yang berfokus pada pengolahan dan analisis basis data akademik menggunakan SQL.  Melalui proyek ini, SQL digunakan untuk memeriksa kualitas data, mengidentifikasi hubungan antartabel, serta menganalisis informasi terkait mahasiswa, mata kuliah, registrasi akademik, dan nilai.
